# P1CODE

Downloads for P1CODE, a Mac workspace for directing coding agents.

## Install

1. Open the latest release on the [Releases page](https://github.com/petersindex/p1code-releases/releases/latest).
2. Download the `.dmg`, open it and drag P1CODE to Applications.
3. Open P1CODE and sign in to the agents you use (Claude, Codex or Cursor) under Settings > Providers. P1CODE runs on your own subscriptions.

P1CODE needs an Apple Silicon Mac. Installed copies check this page and update themselves.

P1CODE is built on [T3 Code](https://github.com/pingdotgg/t3code) (MIT licence).
